# 찬양 콘티 대시보드 — 자동 동기화 버전

모든 기기에서 **같은 데이터**가 자동으로 보이는 버전이에요.
데이터는 브라우저가 아니라 **서버(데이터베이스)** 에 저장돼요.

```
index.html      대시보드 화면
api/login.js    비밀번호 로그인
api/data.js     데이터 읽기/쓰기
api/_lib.js     인증·DB 공통 코드
api/health.js   설정 상태 점검 (로그인 화면에 표시)
api/blob-upload.js  악보 이미지 업로드 토큰 발급
api/blob-delete.js  악보 이미지 삭제
package.json    필요한 패키지 정보
```

---

## 배포 순서 (약 10분)

### 1단계. GitHub에 올리기

Vercel에 데이터베이스를 붙이려면 GitHub 연동 방식이 가장 편해요.

1. https://github.com 에서 새 저장소(Repository)를 만듭니다 (Private 권장)
2. 이 폴더의 파일들을 그 저장소에 업로드합니다
   - 웹에서 하려면: 저장소 화면 → **Add file → Upload files** → 파일 전체를 끌어다 놓기
   - `api` 폴더 구조가 그대로 유지되어야 해요

### 2단계. Vercel에서 프로젝트 만들기

1. https://vercel.com 로그인 (GitHub 계정으로)
2. **Add New… → Project → Import Git Repository**
3. 방금 만든 저장소 선택
4. Framework Preset은 **Other** 그대로 두고 **Deploy**

### 3단계. 데이터베이스 연결하기

1. 배포된 프로젝트 화면에서 **Storage** 탭으로 이동
2. **Create Database → Postgres (Neon)** 선택 → 만들기
3. 그 데이터베이스를 이 프로젝트에 **Connect**

연결하면 접속 정보가 프로젝트에 자동으로 등록돼요. (직접 입력할 것 없어요.)

### 3-2단계. 이미지 저장소(Blob) 만들기 — 큰 악보를 위해 꼭 필요해요

1. 같은 **Storage** 탭에서 **Create Database → Blob** 선택 → 만들기
2. 이 프로젝트에 **Connect**

악보 이미지는 이 저장소에 **원본 화질 그대로** 올라가요.
이 단계를 건너뛰면 앱은 동작하지만, 악보가 자동 압축되어 화질이 떨어져요.

### 4단계. 비밀번호 정하기

1. 프로젝트 화면 → **Settings → Environment Variables**
2. 아래 두 개를 추가합니다

| Name | Value | 설명 |
|---|---|---|
| `APP_PASSWORD` | 원하는 비밀번호 | 접속할 때 입력할 공용 비밀번호 |
| `AUTH_SECRET` | 아무 긴 랜덤 문자열 | 로그인 유지에 쓰는 값 (예: `k3j2h4g8f7d6s5a1q9w8e7r6`) |

3. **Deployments** 탭 → 최근 배포의 **⋯ → Redeploy** 를 눌러 다시 배포

> 환경변수는 재배포해야 적용돼요. 이 단계를 빠뜨리면 로그인 화면에 오류가 떠요.

### 5단계. 접속

`https://프로젝트이름.vercel.app` 으로 접속 → 정한 비밀번호 입력 → 끝!

표 데이터베이스는 처음 접속할 때 **자동으로 생성**되니 따로 만들 필요 없어요.

## 사용 방법

- **폰에서 콘티 입력 → PC에서 새로고침** 하면 바로 보여요.
- 다른 기기에서 수정한 내용은 **1분마다** 그리고 **화면을 다시 켤 때** 자동으로 받아와요.
  즉시 확인하고 싶으면 위쪽 **↻ 새로고침** 버튼을 누르세요.
- **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
  - 아이폰(사파리): 공유 → "홈 화면에 추가"
  - 안드로이드(크롬): ⋮ → "홈 화면에 추가"
- **⬇ 백업 저장** 으로 전체 데이터를 파일로 내려받아 보관할 수 있어요 (안전장치).
- **📊 통계 탭**에서 연도/월별 사용 횟수를 보고, 곡 제목으로 검색하고,
  엑셀 파일(.xls)로 내려받을 수 있어요.

## 주의사항

**비밀번호를 아는 사람은 모두 같은 데이터를 보고 수정할 수 있어요.**
찬양팀끼리 공유하는 용도라 이렇게 만들었어요. 사람마다 계정을 나누고 싶다면
따로 로그인 기능을 붙여야 해요.

**동시에 같은 항목을 수정하면** 나중에 저장한 쪽이 남아요.
여러 명이 같은 콘티를 동시에 고치는 상황은 피해주세요.

**악보 이미지**는 Blob 저장소에 **원본 그대로, 용량 제한 없이** 올라가요
(파일 하나당 최대 100MB). 브라우저에서 저장소로 직접 전송되기 때문에
서버 용량 제한(4.5MB)에 걸리지 않아요.

데이터베이스에는 이미지 주소만 저장되므로 Neon 무료 용량(0.5GB)은
사실상 남아돌아요. Blob 무료 용량은 별도로 제공돼요.

Blob 저장소를 연결하지 않으면 앱은 그대로 동작하지만,
이미지가 자동 압축(최대 1400px)되어 저장돼요.

**악보 이미지 주소는 아는 사람만 열 수 있는 임의의 긴 주소**로 만들어져요.
검색에 노출되지는 않지만, 주소를 그대로 공유하면 로그인 없이도 열려요.

**콘티 인쇄**는 전체화면 보기 안의 **PDF 인쇄** 버튼을 쓰세요.
새 창에서 인쇄 대화상자가 열리면 "PDF로 저장"을 선택하면 됩니다.

## 문제가 생기면

로그인 화면 아래쪽에 **지금 무엇이 빠졌는지 자동으로 표시**돼요.
그 문구를 먼저 확인해보세요.

| 증상 | 확인할 것 |
|---|---|
| `missing_connection_string` / `POSTGRES_URL env var was found` | 3단계 데이터베이스 **Connect**가 안 된 상태예요. Storage 탭에서 Postgres를 이 프로젝트에 Connect한 뒤 **반드시 Redeploy** 하세요. |
| Connect는 했는데 같은 오류 | Settings → Environment Variables 에 `DATABASE_URL` 또는 `POSTGRES_URL` 이 보이는지 확인하세요. 있는데도 안 되면 Redeploy를 안 한 경우예요. |
| "APP_PASSWORD 환경변수가 설정되지 않았어요" | 4단계 환경변수 등록 + 재배포 |
| 비밀번호가 맞는데 안 들어가짐 | `APP_PASSWORD` 값에 앞뒤 공백이 없는지 확인 |
| 로그인이 자꾸 풀림 | `AUTH_SECRET` 을 등록했는지 확인 (없으면 재배포 시 풀릴 수 있어요) |
| "이미지 저장소 오류 — 압축해서 저장했어요" | 3-2단계 Blob을 만들고 Connect한 뒤 Redeploy 하세요 |
| 악보가 흐릿하게 저장됨 | Blob이 연결되지 않아 압축 모드로 동작 중이에요 (위와 동일) |

> **가장 흔한 원인은 "Redeploy를 안 한 것"이에요.**
> 데이터베이스를 연결하거나 환경변수를 추가한 뒤에는
> Deployments 탭 → 최근 배포의 **⋯ → Redeploy** 를 꼭 눌러주세요.
